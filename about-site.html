关于本站 ​

👋 站点简介 ​

本站是一个个人知识沉淀平台，目前主要记录计算机技术相关的学习笔记与实战经验。 未来也可能延伸至作者其他感兴趣的领域——这是一个持续生长的数字花园。

本站的核心理念是：持续输出、终身学习。

🧱 本站技术点 ​

本站基于以下开源技术栈搭建：

分类技术说明
静态站点生成器VitePress 2基于 Vite + Vue 3 的文档站点生成器，构建速度快，支持 Markdown 扩展、侧边栏自动生成
前端框架Vue 3 + TypeScript类型安全，开发体验好，主题与自定义能力强
包管理器pnpm节省磁盘空间，安装依赖速度远快于 npm/yarn
自动侧边栏vitepress-sidebar根据目录结构自动生成学习笔记侧边栏，无需手动维护
主题vitepress-theme-teek一个轻量、简洁高效、灵活配置、易于扩展的 VitePress 主题

🚀 部署架构 ​

本站采用源码私有 + 构建产物公开的双仓库分离架构，同时支持双平台部署：

图片由千问 ai 生成

📍 双平台说明 ​

部署平台适用场景访问特点
Cloudflare Pages（推荐）日常主入口全球 300+ 边缘节点 CDN 加速，国内访问速度快，内置图片自动压缩 / WebP 转码 / 移动端自适应
GitHub Pages（兜底）备份入口与公开仓库绑定，作为 Pages 传统部署方案的兼容保留

🔐 为什么源码放在私有仓库？ ​

  • 避免草稿、未完成内容、敏感配置过早暴露
  • 公开仓库仅保留构建后的静态产物，降低风险
  • GitHub Actions 负责从私有仓库构建后推送到公开仓库，过程全自动
